## Đầu ra mong đợi
Ctrl+V/kéo thả PNG/JPG/WebP, kiểm tra loại/kích thước, lưu ảnh gốc, tạo ID dự án, tránh gửi hai lần.

## Công việc phải xử lý
- [ ] Định nghĩa source hash, project ID
- [ ] API upload dạng multipart có validate
- [ ] lưu ảnh gốc bền vững vào local storage/SQLite

## Checkpoint và Definition of Done
- [ ] .
- [ ] Có nhánh/PR/commit, bản ghi file đã đổi, bằng chứng test và rủi ro còn lại trong [CHECKPOINTS](../CHECKPOINTS.md).
- [ ] Anh xác nhận `OK` nghiệm thu **phân đoạn này** trước khi bước sang phân đoạn tiếp.

## Kiểm thử phải có
Roundtrip byte/hash, restart backend, file MIME giả/oversize, submit lặp.

## Giới hạn, rủi ro cần giải quyết
Dữ liệu cá nhân chỉ được lưu ngoài repo public.

**Điểm dừng:** Nếu phạm vi quá lớn, tách a/b và nghiệm thu từng tiểu đoạn, không tự thực hiện phân đoạn tiếp theo. Chưa có test nghĩa là `CHƯA CHẠY`, không được tự đánh dấu đạt.
